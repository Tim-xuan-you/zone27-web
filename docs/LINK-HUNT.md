# 候選賣場怎麼查

寫這一份是因為 2026-09-19 被 Tim 抓到一個系統性的偏差。

> 「您永遠給我的都是商城耶！蝦皮優選及一般商家，您查不到嗎？畢竟商城都會比較高價，
> 雖然比較有保障！但是畢竟會有不同需求的客群！」

他是對的。不是蝦皮沒有一般賣家，是我查的方式讓一般賣家沒出現。

## 為什麼會全是商城

比價站預設是「推薦排序」。推薦排序把商城的頁面排在前面（權重高、資料完整、有返現標示），
一般賣家散在後面幾頁。我每次只讀第一頁，所以撈出來的永遠是商城。

## 正確的查法

網址後面加 `?sort=lp`，就是從便宜排到貴。

```
https://biggo.com.tw/s/<關鍵字>?sort=lp
```

同一頁還要看兩個東西：

- **賣場名旁邊那一行**：「蝦皮商城」是商城，「蝦皮購物」是優選或一般賣家。
  比價站分不出優選和一般賣家，Tim 點進去看得到標章。
- **連結的 `i=` 參數**：`tw_mall_shopeemall` 是商城，`tw_bid_shopee` 是其他。
  比讀畫面文字可靠。

## 差距有多大（2026-09-19 實查）

| 商品 | 商城 | 一般賣家 |
|---|---|---|
| 臭味滾 極細豆腐砂 7L | $223 | $100 |
| CIAO 啾嚕肉泥 14g×4 | $45 ～ $79 | $25 ～ $39 |
| 艾可 條狀豆腐砂 7L | $128 ～ $179 | $119 |
| 汪喵 太空小零嘴 | $180 ～ $250 | $90 ～ $109 |

臭味滾那一條是一倍以上。一個月算下來 $573 對 $257。

## 規則

1. **每一款的候選名單，至少要有一家商城以外的。**
   只查到商城就在 `note` 寫清楚原因（例如防御工事只在自己的官方商城賣），
   不要讓人以為是漏查。
2. **候選照價格排，不照通路排。** 商城、優選、一般賣家一視同仁。
3. **每一筆都要有 `channel`**：`mall` / `preferred` / `seller`。維護台會標出來。
4. **一般賣家開分潤的比例比商城低。** 所以一般賣家要多給幾家，
   讓 Tim 有得試。試不出來的記進 `data/no-affiliate.json`，那是商品×賣場，不是整家店。
5. **標題看清楚是不是同一個規格。** 一般賣家很愛把好幾個商品寫在一個標題裡
   （「7L/2.8KG 臭味滾 沛點炭」），比價站抓到的最低價常常是別的規格。
   看不準的就不要放進候選，給錯的價格比少給一家更糟。

## 讀者那邊

同一款同時有商城和商城以外的賣場時，價格列表下面會出現一句（`lib/channel.ts` 的 `CHANNEL_NOTE`）：

> 商城是蝦皮認證過的店家，出問題退換比較單純。一般賣家和優選常常便宜一截，買之前自己看一下評價和出貨紀錄。

不講哪一邊比較好。兩種人都有，讓他自己挑。

## 維護台

`/status` 有一段「只連到商城的」，自動列出所有現在只連得到商城的商品。
那一段是零就代表每一款都給了讀者選擇。
