# 商品資料怎麼建

真正的瓶頸不是程式，是這 200 款商品資料。這份給填資料的人看。

## 流程

1. 開 `dog-food.csv`（用 Google Sheet 或 Excel 都行）
2. 一款飼料填一列
3. 存回 `data/dog-food.csv`（**編碼選 UTF-8**）
4. 跑 `npm run data:import`
5. 有錯它會用中文告訴你第幾列哪一欄不對，**而且一列都不會寫進去**
6. 沒錯就跑 `npm run build` 確認頁面生得出來

**不要直接改 `dog-food.json`。**那是產生出來的，下次匯入會被蓋掉。

## 目標

**200–300 款嚴選，不要做到 5000 款。**

蝦皮上有幾萬種狗飼料，其中大部分是分裝包、雜牌、重複賣場。
放 5000 款進來，使用者一樣會選擇癱瘓，那就違背了「幫你刪掉」的初衷。

值得放進來的標準：**指標性品牌、規格查得到、通路穩定、有分潤連結。**

## 欄位說明

### 基本
| 欄位 | 填什麼 | 例 |
|---|---|---|
| `id` | 自己編，不能重複 | `df-001` |
| `brand` | 品牌 | `Orijen` |
| `name` | 品項全名 | `六種鮮魚無穀成犬` |

### 營養（照包裝上的保證分析填）
| 欄位 | 填什麼 |
|---|---|
| `protein` `fat` `carb` | 粗蛋白／粗脂肪／碳水，只填數字不要 % |
| `omega3` | Omega-3 % |
| `phosphorus` | 磷 %。腎臟問題的關鍵指標，一定要填 |

> 三個加起來超過 100% 會被擋下來 —— 通常是抄錯行。

### 成分
| 欄位 | 填什麼 |
|---|---|
| `proteinSources` | 只能填這些：`chicken` `beef` `lamb` `salmon` `whitefish` `duck` `turkey` `pork` `venison` `insect`。多種用 `\|` 隔開，例如 `salmon\|whitefish` |
| `singleSource` | 只有一種蛋白源就 `Y`，否則 `N`。**填 Y 但上面填了兩種以上會被擋** |
| `grainFree` | 無穀 `Y` |
| `prescription` | 處方飼料 `Y`（引擎不會主動推薦處方飼料） |
| `lifeStage` | `puppy` `adult` `senior` `all`，多個用 `\|` |
| `bodySize` | `small` `medium` `large`，多個用 `\|` |

### 使用者回報
| 欄位 | 填什麼 |
|---|---|
| `reportsTotal` | 你統計了幾則評價 |
| `reportsPalatability` | 其中幾則說不愛吃 |
| `reportsLooseStool` | 其中幾則說軟便 |

> 後兩個比第一個大會被擋。樣本少於 30 則，引擎不會拿它扣分。

### 通路與價格

**m1 = 最穩，m2 = 最省。**

- `m1` 填**官方旗艦館／蝦皮商城**那種有保障的（15 天鑑賞、正品保證）
- `m2` 填**高評價大賣家**那種比較便宜的
- 只有一個通路就只填 m1

| 欄位 | 填什麼 |
|---|---|
| `m1Label` | 顯示名稱，例如 `官方旗艦館` |
| `m1Amount` | 售價，只填數字 |
| `m1Note` | 給使用者的差異點，例如 `15 天鑑賞 · 24h 出貨` |
| `m1Url` | **你的分潤連結**（不是商品原始網址） |
| `m1Commission` | 佣金 %。**只用在揭露頁，排序演算法讀不到** |

| `unit` | 規格，例如 `1.5kg` |
| `checkedAt` | 你查價的日期，格式 `2026-09-05`。**這個會誠實顯示在網站上** |

### 最重要的一欄

| 欄位 | 填什麼 |
|---|---|
| `dealbreaker` | **「不要買，如果⋯」的那句話** |

這是整個產品的核心，**沒填會被擋下來**。

寫法：講**使用者的處境**，不要講我們多客觀。

- ❌ 「我們認為這款不適合部分犬隻」
- ✅ 「你的狗曾對羊肉起疹 — 單一蛋白源沒有備援」
- ✅ 「你的狗挑食 — 142 位回報者中有 31 位反映適口性差」
- ✅ 「碳水 34% 偏高 — 需要控制體重的狗不適合」

**用具體數字，不要用形容詞。**

### 其他
| 欄位 | 填什麼 |
|---|---|
| `discontinued` | 停產或長期缺貨 `Y`（引擎會直接排除，但仍列出理由） |

## 常見錯誤

| 訊息 | 怎麼修 |
|---|---|
| `「chikcen」不在允許清單內` | 拼錯了，照上面的清單填 |
| `checkedAt 格式要像 2026-09-05` | 用 `2026-09-05`，不要用 `9/5` |
| `回報人數比總回報數還多` | 抄錯行了 |
| `標了單一蛋白源，但填了 2 種` | 兩邊對不起來，改一邊 |
| `還是佔位連結` | 這是警告不是錯誤 —— **上線前一定要換成真的分潤連結** |

## 規格要填幾個？—— 有幾個填幾個

**看到幾個規格就填幾個。** 之前我訂了「省超過 25% 才值得」，那條規則是錯的，
因為我只算了維護成本，沒算收入：

```
FirstMate  1.8kg  $748   × 3.5%  =  $26
           6.6kg  $2,317 × 3.5%  =  $81     多 $55

Natural Balance
           4.5磅  $1,050 × 11%   =  $115
           24磅   $3,450 × 11%   =  $380    多 $265
```

**大包不是小加分，是客單價直接變三倍。** 多查一次價格換每單多賺兩百多塊，
這筆帳怎麼算都值得。

### 怎麼填

- 同一個商品頁多規格 → `m1Unit` `m2Unit` `m3Unit` `m4Unit` 填不同容量，
  網址填同一條。畫面會變成「一個賣家標題 + 一個按鈕 + 規格表」
- 賣家把尺寸拆成獨立商品 → 每個 `mNUrl` 填各自的網址。
  畫面會變成「一個賣家標題 + 每行各自一個按鈕」
- **`mNLabel` 都填同一個賣家名稱**，畫面才會歸成一組

### 網站會自動算三件事

| 自動算的 | 來源 |
|---|---|
| 每公斤單價 | `mNUnit` + `mNAmount`，認得 kg／公斤／磅／lb／g |
| 每公斤省幾 % | 以最小包為基準。差三個百分點以內顯示「差不多」，更貴會用紅字寫「反而貴 X%」 |
| 這包吃得完嗎 | 體重 × 2% 估日食量。超過 45 天會標 ⚠️ 並解釋油脂氧化的問題 |

**最後一項是這個站跟推銷的分界線。** 同樣一包 11.4kg 的 ACANA：
拉不拉多吃 19 天（每公斤省 36%，該買），吉娃娃要吃 114 天（開封快四個月，別買）。

**既講便宜多少，也講會不會放到壞。**

## knownIssues：飼主常提到的狀況

**這一欄取代了原本想做的「142 位中有 31 位反映適口性差」。**

那種數字我們拿不到 —— 蝦皮的評論不能爬，硬編就是說謊。
但質性描述查得到、標得出來源，而且更有用：

```
❌  142 位回報者中有 31 位反映適口性差
✅  顆粒比多數品牌大，小型犬可能不好咬
✅  換糧期比較容易軟便（纖維偏高），建議分 7–10 天慢慢換
```

**「顆粒偏大」比一個百分比實用得多** —— 它直接告訴養吉娃娃的人要注意什麼。

### 從哪裡找

PTT `dog` 板、Dcard 寵物板、各飼料評測網站的留言區、品牌社團。
搜「品牌名 + 缺點 / 軟便 / 適口性 / 顆粒」通常一次就找得到。

### 怎麼寫

- **講具體的狀況，不要下判斷**
  ❌「品質不穩」　✅「換糧期軟便的回報較多」
- **有解法就一起寫** —— 「建議分 7–10 天慢慢換」
- **牽涉到我們自己的選擇就講清楚** —— 「我們列的是小顆粒版本」

畫面上會標「整理自公開評價與討論區，不是系統性統計」，
所以不用假裝精確，但也不能寫沒有根據的東西。

**沒查到就留空**，畫面會顯示「這款我們還沒整理飼主回報」並邀請使用者回報 ——
那正是失敗案例庫的原料來源。

## 碳水（carb）這一欄是推估的，不是廠商標示

台灣的保證分析不標碳水。這一欄用 NFE 推估：

```
碳水 ≈ 100 − 粗蛋白 − 粗脂肪 − 粗纖維 − 水分 − 灰分
```

灰分廠商多半也不公布，沒有的就用該類型的典型值（無穀高蛋白約 8–9%、
穀物基底約 7–8%）。**所以這個數字有 ±3% 的誤差，不要拿它去做太細的判斷。**

門檻定在 48% 就是因為這個 —— 它只用來擋明顯離譜的，不是拿來排名。

## referenceOnly：對照款

填 1 的那幾列是**放進來被刪掉的**，不是要推薦的。

這個站的說服力來自排除過程。如果選品全是同一種好東西，任何規則都刪不到人，
「怎麼刪的」就是一張空表，使用者什麼也沒學到。所以主流雞肉配方、
平價高碳水糧、幼犬專用、大型犬專用這些必須在池子裡。

對照款**不需要分潤連結**（m1Label 可以空著）。萬一它撐過所有條件沒被刪掉，
引擎會用最後一刀砍掉它，理由是「沒有我們查證過的購買通路」—— 那是實話。
等哪天真的查到通路，把 referenceOnly 清空，它就變成正常商品。

## poultry：成分表只寫「禽肉」

`proteinSources` 多了一個 `poultry`，意思是**成分表只寫「禽肉」「家禽肉類及副產品」，
沒有指明是哪一種鳥**。

平價糧非常常見。對正在排查過敏原的人來說這是致命的 ——
你不可能從標示上排除雞肉，因為它根本沒說。所以只要使用者要避開
雞、火雞或鴨的任何一種，含 `poultry` 的一律排除。
