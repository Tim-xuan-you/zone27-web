# 第五個類目：貓零食（ct-）

2026-09-19 決定。Tim：「下一類別有什麼建議？一樣寵物類？」

## 為什麼是貓零食

1. **跟現在要養的那群人同一批。** 帳號只有一個，前三篇 Threads 都是貓的題材（藏雞、貓砂沖馬桶、貓砂月花費）。第一批追蹤的人是養貓的，下一個類目要給他們第二個回來的理由。
2. **衝動購買、單價低、天天買。** 飼料換一次要觀察兩週，零食是看到就買。回頭率最高的品項。
3. **招牌題材現成的：**
   - **肉泥九成是水。** CIAO 啾嚕肉泥的保證分析寫水分 91%，一條 14 克裡面只有大約 1.3 克是乾物。日系標示常常不把水列進成分表，所以要看的是分析表那一格，不是成分表第一項。
   - **熱量沒有人在算。** 獸醫的通則是零食不超過一天熱量的 10%。一隻 4 公斤的成貓一天大約 200 大卡，零食上限 20 大卡；一條肉泥大約 7 到 9 大卡 —— **一天兩條就到頂**。很多人一天給五六條，還在問貓為什麼胖。
   - **「主食凍乾」不等於主食。** 有的包裝寫主食，但營養標示根本不是完整均衡配方。
4. **接得回舊類目。** 很多零食是雞肉做的，對雞過敏的人查完飼料，會接著問零食。/check 可以延伸過來。

## 招牌頁

`/cat-treat/how-many`（暫名）：**「這包零食，一天可以給幾條」**
輸入貓的體重（沒填就照 4 公斤），每一款算出一天的上限。

算法寫清楚給讀者看：
1. 一天要幾大卡：照體重算（跟 /cat-food/how-much 同一套）
2. 零食上限＝一天熱量的 10%（獸醫通則）
3. 有「一條幾大卡」的，換算成幾條；只有「每 100 克幾大卡」的，換算成幾克
4. 兩個都沒有的，就寫「包裝沒公布熱量」，不要編
跟飼料的「一天幾克」、罐頭的「一天幾罐」、貓砂的「一個月多少錢」同一個家族：把包裝上沒寫的那個數字算出來。

## 資料要記什麼（TreatSpec）

| 欄位 | 說明 | 為什麼要 |
|---|---|---|
| `form` | 肉泥／凍乾／肉條／餅乾／凍乾撒粉 | 決定怎麼算、怎麼比 |
| `kcalPer` | 一條或一顆幾大卡 | 「一天幾條」的分母。沒公布就留白，不推估 |
| `kcalPer100g` | 每 100 克幾大卡 | 凍乾多半論克賣，用這個算「一天幾克」 |
| `moisture` | 水分 % | 肉泥的關鍵數字：91% 的水 |
| `unitZh` | 條／顆／片／包 | 講法要跟包裝一致 |
| `piecesPerPack` | 一包幾條 | 算每條多少錢 |
| `firstIngredient` | 成分表第一項 | 肉泥的第一項常常是水 |
| `proteins` | 肉的來源（跟飼料同一套） | 對雞過敏的人要查得到，可以接 /check |
| `additives` | 增稠劑、誘食劑、色素之類 | 讀者最想知道又最難查的 |
| `completeFood` | 是不是完整均衡（能當主食） | 「主食凍乾」不一定是主食 |
| `note` | 先知道這件事 | |

## 刪掉的規則

- 「對雞過敏」→ 刪掉含雞的（跟飼料共用 proteinSources）
- 「要控制體重」→ 照每條熱量排，高的往後
- 「要能當主食」→ 只留 completeFood
- 「不要添加物」→ 刪掉有增稠劑、誘食劑的

## 做法

- 編號 `ct-`，CSV `data/cat-treat.csv`，Sub id 第二格 `cattreat`
- 型別另開 `lib/treat.ts`，不要塞進飼料的 Spec（跟貓砂同一個作法）
- 共用：賣場名冊、連結管理、/go 跳轉、維護台、分享卡、設計
- 熱量沒公布的就留白，「一天幾條」那一格寫「包裝沒公布熱量」，不要編一個數字
